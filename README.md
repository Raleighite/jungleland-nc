# Jungle Land NC

Community archive and virtual recreation of **Jungle Land** — the beloved amusement park that once stood in Atlantic Beach, NC.

🌐 **[junglelandnc.com](https://junglelandnc.com)**

## About

Jungle Land was a cherished amusement park on the North Carolina coast. Though the park is gone, its memory lives on. This site is a community-powered effort to preserve and recreate Jungle Land through photos, videos, stories, and eventually an interactive virtual experience.

## Contributing

Have photos, videos, or memories of Jungle Land? Submit them at [junglelandnc.com/submit](https://junglelandnc.com/submit).

## Tech Stack

- [Next.js 14](https://nextjs.org/) (Static Export)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## Development

```bash
npm install
npm run dev
```

## Deployment

This site is statically exported and can be deployed to any static host (Vercel, Netlify, Cloudflare Pages, etc.).
